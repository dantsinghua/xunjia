# 工作流 —— 谈价状态机 / 归属路由 / 跨日续谈 / 转人工(v1.0)

一切以 v1.0 需求书为准(旧版策略说明的状态机/5类意图/超时/并发口径已作废)。

## 1. 谈价状态机(session.state)

```
[待发起 PENDING]
   │ 交易员在意向询价点击触发
   ▼
[第N轮已发出 ROUND_SENT] ──▶ 等待回复(不设超时)
   │
   ├─ 拿到实价 ─────────────────────▶ [转人工 TO_HUMAN] ★核心产出
   ├─ 虚价/模糊 ─▶ [追问量 ASK_VOL] ─┬─ 转实价 ─▶ TO_HUMAN
   │                                └─ 仍模糊 ─▶ TO_HUMAN
   ├─ 明确拒绝 ─┬─ 仍有让步空间 ─▶ [第N+1轮 ROUND_SENT]
   │            └─ 已到探价边界 ─▶ [结束:未获实价 CLOSED_NOPRICE]
   ├─ 非价格条件/反问/加量超可投量 ─▶ TO_HUMAN
   ├─ 归属不明 ─────────────────────▶ TO_HUMAN
   └─ 长期无回复 ─────────────────────▶ [挂起 SUSPENDED] ──跨日──▶ §3
```

**规则**:
- 每轮在上一轮基础上让 `步幅`;越过探价边界则钳到边界(末轮不越界)。
- 轮次上限 `=(起始−边界)/步幅+1`,派生。到边界仍未拿实价 → CLOSED_NOPRICE,保留全部留痕。
- 不设单轮超时、不设并发上限(人工逐个触发)。
- **报价/让步/比大小一律规则引擎算,不给模型。**

## 2. 实价 / 虚价判定(核心产出的门)

| 判定 | 特征 |
|---|---|
| 实价 | 明确价格 + 明确/可确认的量 + 无模糊限定 + 无附加条件(例:"1.86 可以出 3000") |
| 虚价 | 出现 大概/参考/估计/差不多/意向/看看;只给方向不给数;给价但"我要问一下/报备一下" |
| 拿不准 | 按未拿到实价处理 |

**验证手段=追问量**:`这个价能出多少量?` 每会话最多一次。给明确量→升级实价→转人工;仍模糊→转人工由交易员判。

## 3. 多券上下文归属(L1–L5 阶梯,命中即停)

thread(对手)vs session(意向×对手×券)。消息到 thread 必先路由到 session。**归属错=实价挂错券,代价最大。**

| 级别 | 依据 | 置信 | 动作 |
|---|---|---|---|
| L1 | 回复含债券代码或可唯一定位的简称片段 | 高 | 直接归属 |
| L2 | 平台引用/回复关系(若支持) | 高 | 直接归属 |
| L3 | 该对手当前只有 1 个未闭合会话 | 高 | 归属 |
| L4 | 价格线索只落某券合理估值区间 | 中 | 归属 + 标记待确认 |
| L5 | 时序就近(最近一条我方询价+时间窗) | 中低 | 归属 + 标记待确认 |
| — | 都不成立 | — | **归属不明 → 转人工,绝不猜** |

**工程保障(比算法管用)**:① 我方每条消息必带券锚 `bid {code} {简称} {量}W 估值+{N}能出么`,不能省简称;② **推荐串行**(同对手同时只 1 个未闭合会话,L3 覆盖绝大多数);③ 若并发:每轮加短锚前缀 `【苏科技城】`,L4/L5 打标可一键改归属,归属不明不进策略引擎。

**必处理**:600 字截断先拼接再归属(顺序反了归错券);一条涉多券拆分归属,任一段拆不准整条转人工;对方主动发别的券报价→转人工(有采集价值);撤回→按撤回前回退。**归属依据必须留痕**(事后可查挂错哪级)。

## 4. 跨日续谈("说话前先看一眼")

会话跨自然日后,**发下一条消息之前**先走:拉当日 中债估值/对方报价/本方可投量 → 与上次会话快照比对 → 判定:

| 情形 | 判定 | 动作 |
|---|---|---|
| 估值变动 ≤ S2(默认3BP)且对方报价在 | 可续谈 | 沿用原策略与已让步位置 |
| 估值变动 > S2 | 重置 | 按当日估值重算起始/边界,让步清零 |
| 对方报价撤销/当日无报价 | 挂起 | 不发,提示交易员 |
| 本方可投量归零 | 关闭 | 提示,不再续谈 |

**跨日第一条消息必须人工确认后才发。** 话术带时间锚:续谈"昨天聊的…今天还是…能出么";重置"今天重新看了下…"(**绝不沿用昨天价直接问**)。

## 5. 意图分类(模型唯一职责)→ 动作

模型只输出下列之一 + 结构抽取,不判好坏:

| 意图 | 动作 |
|---|---|
| 实价 | 转人工 ★ |
| 虚价/模糊 | 追问量→仍模糊转人工 |
| 明确拒绝 | 有空间→下一轮;否则结束 |
| 还价(带数字) | 交规则引擎与边界比大小 |
| 非价格条件(清算+0/+1、**过券/过桥**、含权口径) | 转人工 |
| 反问("你出个价/什么量/你哪家") | 转人工 |
| 挂起类("等会回你") | 保持等待,不追问 |
| 噪声(寒暄/表情/红包/系统) | 忽略(复用存款 NOISE) |

抽取形如 `{意图:还价, 基准:估值, 偏离:+5BP, 量:3000}`。

## 6. 转人工触发(固定规则,不配置)

拿到实价 / 追问量后仍模糊 / 非价格条件(尤其过券过桥,换了实际对手换了授信结算成本) / 加量超本方可投量 / 反客为主要我方报价 / 归属不明 / 对方发其他券报价。

**话术**:对对手方 `您好,等我内部请示下`(争取介入时间 + 不构成要约);对本方交易员(外网 QT 私聊)`102400895.IB 24苏科技城MTN001 3000W,对方报实价 1.86/3000,是否介入`。

## 7. 方向与符号(写死,不配置)

买入(bid):收益率越高越有利。`估值+10=起始(最有利) / 估值+5=探价边界 / 估值+3=已越界`。对手回"估值+3可以出"是**比边界更差=拒绝**,不是成交信号。卖出(ofr)镜像:起始=估值−10、边界=估值−5,让步方向相反。**符号写死在代码,配成参数迟早填反=反向让利。**

## 8. 合规硬约束(出口闸)

禁要约词(我们要了/成交/按这个价做);禁外泄内部字段(含/不含担保可投量、产品代码、组合号、本方交易员姓名、授信、持仓);对外只留 方向/代码/简称/询价量/价格条件。触边界一律"请示一下"收口。全量留痕:每轮原文、对方原文、意图、归属依据+置信级别、规则判定、转人工时点与应答(只增不改版本链)。
