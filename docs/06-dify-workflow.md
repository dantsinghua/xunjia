# Dify Chat Agent

本页替代旧版WF1/WF2抽取工作流说明。聊天核心使用Chatflow（Dify应用模式advanced-chat）和经典Agent节点，调用`/v1/chat-messages`；不再从监控GET请求触发生成，也不回退到workflow接口。

当前实现与导入包见[交付说明](../dify/chatflow_1171/README.md)，业务裁决见[Chat Agent设计](2026-10-13-dify-chat-agent-design.md)。

私有上下文通过固定HTTP能力节点读取；Agent仅拥有债券、相似券、发行人和计算器四个公共只读工具。独立工具预算票据最多允许每轮6次查询，历史补取最多一轮。公开措辞节点仅接收已筛选的公开事实，最终正文必须由后台重新核验。模型输出、HTTP200和上传成功均不代表命令已执行。

后台持久化会话、授权、记忆、歧义次数、命令和回执；停止/接管使旧控制版本失效。Dify只是提出行动，后台决定能否提交；结果未知时对账，不自动重发或换路。

Dify 0.15.3的既有实例不在本次隔离测试中改动。新包锁定1.17.1源码与实际安装插件；升级、导入与业务数据迁移证据分别记录，不合并为一个“已上线”结论。
