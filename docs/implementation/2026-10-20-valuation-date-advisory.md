# 2026-10-20：BP估值日期改为提示信息

安琳本次明确要求：直接使用Innodealing明确标注的中债估值估算BP；估值日或发布日期可显示和提示，但不是预览、确认、刷新或跨日前置条件。正式中债数据有可用来源时可读取；不能要求用户先配置发布日历。这一要求覆盖历史文档中将估值日期、最新发布日匹配设为强制阻断的条款。

- 优先采用当前Innodealing中债估值。该值可用时不再查询正式资料源或发布日历；没有可用值时才使用已配置的中债资料源。
- 预览显示实际采用的来源、原始估值、源日期（缺失为null）及提示。不得填今天、报价时间或猜测日期，也不更新历史NULL值。
- 未知、无效、旧或未来估值日期不阻断，不要求跨来源估值对账。日期并非有效性承诺。
- 仍要求同券合法数值；买卖报价、净价不能替代中债估值。没有任何可用中债数值时明确说明，不能伪造。
- BP先按完整估值精度加偏移，再按既有规则取两位。本人方向、数量、起始收益率与边界、收件人、账号、幂等及二次授权保护保持。
- 预览确认时，仅日期、快照编号变化且实际数值与来源未变，不要求重新预览；实际采用的估值数值或来源变化仍须重新核对。
- 日期变化不改变已授权经济条件，也不取消命令。实际变价仍走原CAS、重算和旧命令取消流程。
- 对手报价的交易日确认、结算日、指令有效期、发送权限和UNKNOWN对账不是估值日期，不在本次放宽范围。

原文核对发现当前报价有明确中债数值，另有日期形状的未命名protobuf字段；尚无协议定义能将其认定为估值日或发布日期。未猜测字段映射，日期未知不影响本次估算。

验收必须覆盖当前旧库NULL日期、无日历的实际create_app入口，以及真实Innodealing行到服务端预览和页面。不能仅靠向测试应用注入合成日历证明本机可用。
