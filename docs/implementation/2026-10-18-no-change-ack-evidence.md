# 无报价变化的短应答职责

安琳，现金问结算的真实往返暴露了两种模型错误：第18版把我方问句中的 T+0/T+1 当作对方结算回答；第19版已正确输出空观察，但把提示里的“当前入站ID”占位词原样返回。两轮现金分别都是3/4，后端均拒绝错误结果，原现金价量没有被改写，后续完整47例没有启动。

当前实现只给封闭的“稍等／等一下”应答减负：唯一成员、所有当前入站均严格匹配该短回复、其余出站均有可信成员关联时，使用短的 A 提示。带价量、撤改、最终性、指代、条件、问句、未知券或其他内容均保持原联合语义流程；repair、工具、历史及纠正上下文不能选择此提示。完整原文、20条上下文和候选仍保留。

短提示提供已绑定本快照真实入站 ID 与成员 ID 的完整 JSON 对象，模型仍返回其响应。Code 不替换占位词、不删除错误观察、不将我方出站问题变成本人确认。合法空观察保留原价量、确认日和最终性；发送回执变 UNKNOWN 不会被升级为经济确认。

独立门覆盖两版生成图、路由边界、上下文保留、实际 Code→Engine→Store 和 SENT/UNKNOWN 竞态。原53项通过后追加4项 ID 绑定正反例，原53项保持；新增两版提示未绑定的2红已修，针对性57项通过。四份静态 DSL 须继续通过原一致性门。真实模型效果和完整新版本验收另记，不凭本地门宣布最终完成。

证据保存在本机运行目录的 `no-change-ack-independent`、`no-change-ack-bound-independent`、`api-settlement-r18` 和 `api-settlement-r19`。原失败成绩保留，不与新版结果拼接。
