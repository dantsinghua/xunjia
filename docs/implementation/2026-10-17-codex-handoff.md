## 4. 最新已确认的业务规则（不要再重复询问）
### 4.1 组织与控制
- 顶层券A组/券B组，每券有多个对手子会话；同一个企点线程可以谈多券，线程不等于子会话。
- 对手a的A券改量，只更新a的A券；b的A券改价，只更新b；共享量变化可以使其他对手旧询量候选失效，但不能改写其价格事实。
- 首次询价可以合并多券发送，后续逐条识别涉及的券并分别回复。撤价/ref/不做/下架等要结合上下文影响单券，其他券继续。
- 停止只关闭发送；人工接管、暂停、等待回执、UNKNOWN期间，接收、解析、事实更新和前端分析都继续。
- 原文及已知收件字段立即落库显示，与解析异步。结构化价量后续补齐，不等待回执；解析未完成不能猜填新价格。
- 全局统一上下文默认20条同券同对手双方实际原文，环境配置XUNJIA_BOND_CONTEXT_MESSAGES，10..30；Dify不能另维护冲突值。引用锚不足时按ID补取；未发草稿不是“我刚才的价”。
- “行”“可以”“要了”“按你刚才那个价”不得单独作为停机/成交判据。先识券、读取该券双方近10~30条、恢复指代，再比较当前价格/量及谈判目标。
### 4.2 价格、数量、最终价
- 默认收益率报价无须百分号。价格与数量先作语义分类，不把数量的小数当第二个收益率。
- 收益率统一Decimal ROUND_HALF_UP到小数点后两位；中债完整估值先加减N/100，再最终四舍五入，不能先round估值。
- 必须通过：2.5818估值-5收=>2.53%收，可简称53收；2.9872估值+5BP出=>3.04%出，上下文04出应还原3.04，不是2.04。
- “2.20，0.5亿”=>2.20%、5000万；明确同券2.xx上下文中“20 5000”=>2.20%、5000万。不要求人工补写%或w。
- 单位按惯例+上下文双重确定；缺乏任何整数位/单位依据时不要为达goal猜数，标明缺口/询问。
- 净价/全价显式关键词分别识别。净价34.19出不能解作34.19%收益率。
- 净价换收益率或应计必须先向对手确认结算日是T+0还是T+1/明确日期，无暗设默认值。还需可靠现金流、付息规则、条款快照；缺资料时保留原始净价并明确换算缺口，不伪造收益率。
- bid价格/收量与ofr价格/出量独立保存；未提不改，改量不累计，查询/询量不作确认量；补字段可引用同券同对手有效上下文并保留来源。
- 本项目“最终实价”是上下文/意图判断出的本轮最优且不能再改善的报价，不是关键词判定。初始价一分不让但明确最终无空间，也可判最终。反报价、撤回、意向、问句、未知、谈判空间和可用性分开。
- 最终性绑定具体报价版本和语境证据；新价/新量/新条件不能盲继承旧FINAL。报价仅到内部边界但仍有改善空间，继续谈。
- 一小时未回复进入“未响应”；结合已有明确拒绝等上下文判断，不因沉默自动FINAL或确认可交易。
### 4.3 券组共享量与goal
- 同券共享总量，不对每个对手机械重复索要授权全量。
- 已报有效总量决定是否继续扩量；价格达标、当日有效、最终确认的量决定是否满足目标。未达目标价的量不计已满足量。
- 确认量>=目标即可（等于也算）。达到合格最终量允许提前交人工并停止该券组自动谈判，其他券组继续、分析不停。
- 不能一家报1500万机器人自行决定只拿500万；整量列表交人工配量，不作成交/锁量/额度占用承诺。
- 多目标：量够不代表价格够；收3.12目标1000万，对手3.05出1000、3.10出500，则达价覆盖量0，继续谈。
- gap要有交易方向，显示剩余差距与优于边界的改善，不能用绝对距离把有利价格丢弃。不得擅自允许一家好价平均补偿另一家低于单家底价的报价。
- 人工方案所依赖报价撤回/修订时标记需复核，不能维持旧“覆盖达成”。不要自动恢复被人工停止的发送。
