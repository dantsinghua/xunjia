# 当前唯一运行合同

生产入口：`server.app:create_app`；业务核心：`server/negotiation/`；传输：`its-relay-path-v1`。
不保留旧业务后台、双通道邮件回退、本地队列协调器或旧 Dify Agent 流程。
当前模型源码为 `dify/negotiation_v22/`，导出到 `chatflow_0153/v22-*.yml` 和 `chatflow_1171/v22-*.yml`。

更换工作台、企点号或实质改变机构连接配置时，清空该工作区旧询价、暂停、发送及未知结果状态，建立全新账号上下文。
不会迁移或重发旧任务；原生企点聊天记录不被删除，新号历史按新号读取。
相同账号与相同配置的重复保存、读取缓存不清空业务。

直接发送不强制预览。通道不可用时明确拒绝新提交，不排队等待恢复。
已提交请求查询使用原编号，不重复生成命令；只有原生回执证据才能显示已发送。
BP边界由服务端估值折算，初始收益率不与谈价边界作提交比较。

运行验收必须分别核对完整回归、当前绑定与后台、真实企点发送与回执；不能用目录在线代替消息链路验收。
